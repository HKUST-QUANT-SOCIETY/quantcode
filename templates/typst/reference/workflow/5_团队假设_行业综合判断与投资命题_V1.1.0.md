## 一、阶段定位

本阶段是整个行业研究流程的决策综合阶段。

前四阶段已经完成：

- 长期产业地图维护；
- 研究项目立项；
- 技术与产业链拆解及研究；
- 标的池建立与公司标准化全覆盖。

因此，本阶段不再重复搜集基础资料，而是将已有行业事实、产业链判断、公司竞争分析、财务底稿和当前估值，转化为团队对未来的共同判断。

本阶段需要回答：

1. 团队对未来一至两年的行业需求、供给、技术、价格和竞争做出什么判断；
2. 这些行业变量分别影响哪些产业链环节和公司；
3. 公司收入、利润、现金流和资本回报在不同情景下如何变化；
4. 当前市场一致预期和股票价格已经反映了什么；
5. 团队与市场之间是否存在有证据支持的预期差；
6. 该预期差是否足以形成可验证、可推翻的投资命题。

本阶段的核心逻辑是：

> 事实底稿 → 团队假设 → 情景分析 → 盈利映射 → 估值比较 → 预期差 → 投资命题。

本阶段不负责实际仓位、交易时点、止盈止损和组合风险预算。研究判断与资金决策应保持分离。

---

## 二、阶段起点与终点

### 2.1 阶段起点

本阶段从第四阶段通过验收后开始。

进入本阶段前，应至少具备：

- 完整的《行业研究主文档》；
- 完整的《行业标的主表》；
- 所有正式入池公司的《公司标准化研究报告》；
- 公司行业映射、竞争格局、财务状况和当前估值底稿；
- 市场一致预期；
- 主要资料缺口和待验证问题；
- 需要团队讨论的关键假设清单。

如果公司基础事实、财务数据或产业链映射仍然存在重大缺口，应先返回第四阶段补充，而不是在本阶段以主观假设替代缺失事实。

### 2.2 阶段终点

本阶段只有在以下事项全部完成后才算结束：

- 团队共同假设已经形成；
- 悲观、基准和乐观情景已经形成；
- 行业综合投资判断已经完成；
- 主要公司已经完成情景盈利和合理估值；
- 全部正式标的已经进入公司比较与估值矩阵；
- 主要预期差、催化剂和风险已经明确；
- 具备条件的公司已经形成《投资命题卡》；
- 不具备机会的公司已经形成等待、暂不参与或排除结论；
- 行业整体不存在机会时，已经形成否定性行业命题；
- 市场当前定价的核心叙事、关键指标和盈利修订方向已经明确；
- 每项拟进入投资决策的命题已经说明收益来源、时间范围、下行情景和验证路径；
- 项目总负责人确认可以进入投资决策与组合管理阶段。

## 三、目标

### 3.1 形成团队共同假设

将分散在行业研究和公司报告中的未来判断，收敛为团队共同使用的：

- 核心变量；
- 基准值或区间；
- 悲观、基准和乐观情景；
- 置信度；
- 验证指标；
- 主要影响公司。

团队成员可以保留异议，但必须明确分歧发生在哪个变量、哪项证据或哪种情景上。

### 3.2 形成行业综合判断

对行业形成简明的 overall，至少回答：

- 行业当前处于什么阶段；
- 未来一至两年的核心驱动；
- 需求、供给和技术路线如何变化；
- 价格和利润向哪些环节迁移；
- 市场当前的主流预期是什么；
- 团队与市场的主要分歧是什么；
- 行业整体是否存在值得参与的投资窗口。

本阶段不重新复制第三阶段的完整技术和产业链内容，而是说明这些研究结论对于盈利和投资意味着什么。

### 3.3 将行业假设映射至公司盈利

明确行业变量如何影响各公司的：

- 销量；
- 产品价格；
- 市场份额；
- 产品结构；
- 毛利率；
- 费用率；
- 净利润；
- 经营现金流；
- 资本开支；
- 资本回报。

### 3.4 形成合理估值区间

在第四阶段当前估值底稿的基础上，使用团队盈利假设形成：

- 悲观情景估值；
- 基准情景估值；
- 乐观情景估值；
- 相对当前市值的潜在上涨或下跌空间；
- 各情景成立的必要条件。

### 3.5 识别真实预期差

判断：

- 市场目前相信什么；
- 团队与市场在哪个变量上不同；
- 团队为什么更可能正确；
- 这种差异如何影响盈利和估值；
- 什么时候可能被市场验证；
- 当前风险收益是否足以支持投资命题。

### 3.6 理解市场定价、收益来源与时间路径

团队需要说明：

- 当前市场主要在交易什么叙事和经营指标；
- 盈利预测处于上修、下修还是分歧扩大阶段；
- 当前估值处于什么行业和市场环境；
- 股价过去对哪些订单、财报、利润率或资本开支变化最敏感；
- 未来收益主要来自盈利增长、盈利上修、估值修复、估值扩张、分红回购还是周期反转；
- 市场重新定价需要多长时间和什么催化；
- 悲观情景下的下行空间和损失来源是什么。

### 3.7 形成可证伪投资命题

每个正式投资命题必须包括：

- 核心判断；
- 市场当前预期；
- 团队预期差；
- 事实基础；
- 关键推断；
- 关键假设；
- 盈利和估值影响；
- 催化剂；
- 主要风险；
- 反证条件；
- 重新评估条件。

没有明确预期差、催化和风险边界时，不强行形成投资命题。

## 四、输入

### 4.1 《行业研究主文档》

用于提供：

- 行业需求；
- 技术路线；
- 产业链；
- 产业化阶段；
- 核心瓶颈；
- 价值量和利润迁移逻辑。

### 4.2 《行业标的主表》

用于：

- 确定公司比较的完整范围；
- 确认公司产业链位置；
- 避免只比较少数热门公司；
- 调取公司覆盖状态和研究报告。

### 4.3 《公司标准化研究报告》

用于提供：

- 公司行业映射；
- 竞争位置；
- 财务状况；
- 当前估值；
- 市场一致预期；
- 主要风险；
- 待讨论问题。

### 4.4 市场一致预期

包括：

- 收入预测；
- 利润预测；
- 毛利率预测；
- 资本开支预测；
- 目标价；
- 当前估值；
- 预测上修和下修趋势。

一致预期是市场定价的参考，不等同于团队判断。

### 4.5 最新行业与公司数据

包括：

- 最新财报；
- 公司指引；
- 客户资本开支；
- 订单和出货数据；
- 产品价格；
- 产能；
- 技术和认证进展；
- 政策和监管变化。

### 4.6 历史估值与可比公司资料

用于：

- 选择估值方法；
- 确定合理倍数；
- 判断当前历史分位；
- 比较公司之间的估值溢价和折价。

### 4.7 市场定价与预期变化资料

包括：

- 分析师盈利预测及其上修或下修；
- 公司指引与市场预期差异；
- 重大财报、订单、产品和政策事件后的价格反应；
- 行业和公司估值分位；
- 可比公司相对表现；
- 市场当前关注的关键经营指标；
- 机构持仓、资金流或市场拥挤度等公开且可靠的数据。

持仓和资金数据只能作为辅助信息，不能替代基本面和估值判断。

### 4.8 团队讨论记录

用于保存：

- 成员初始观点；
- 主要分歧；
- 假设调整；
- 最终共识；
- 保留意见；
- 后续验证条件。

## 五、主要动作

### 5.1 确定研究期限和决策问题

项目总负责人首先明确：

- 主要预测期限，通常为未来一年和未来两年；
- 投资命题预计验证的时间范围；
- 是否需要三至五年的长期判断；
- 本阶段希望回答的行业和投资问题；
- 哪些公司需要完整情景估值；
- 哪些公司当前只需要保留观察结论。

### 5.2 建立团队假设表

团队假设应围绕行业最关键的变量展开，包括：

- 下游需求；
- 客户资本开支；
- 产品需求量；
- 技术渗透率；
- 产品价格；
- 产能和供给释放；
- 市场份额；
- 毛利率；
- 费用率；
- 资本开支和现金流。

每项假设至少记录：

| 字段 | 内容要求 |
|---|---|
| assumption_id | 假设唯一编号 |
| variable | 假设变量 |
| current_fact | 当前已确认事实 |
| market_consensus | 市场一致预期 |
| team_base_case | 团队基准情景 |
| team_bull_case | 团队乐观情景 |
| team_bear_case | 团队悲观情景 |
| confidence | 高、中或低 |
| affected_companies | 主要影响公司 |
| validation_indicator | 验证指标 |
| owner | 负责更新成员 |
| latest_update | 最近更新时间 |

所有假设必须区分：

- 已确认事实；
- 公司或券商预测；
- 市场一致预期；
- 团队假设。

不得把公司指引或券商预测直接视为团队结论。

### 5.3 识别市场当前定价框架

在建立情景前，团队需要形成对市场状态的共同理解：

- 市场当前主要交易什么行业叙事；
- 投资者最关注哪些经营指标；
- 盈利预测近几个季度是上修还是下修；
- 行业估值处于扩张、收缩还是分化阶段；
- 同一行业内估值差异由什么解释；
- 公司股价对财报、订单、产品、资本开支和毛利率变化如何反应；
- 当前价格反映的是短期周期、长期成长、稀缺性还是主题情绪；
- 哪些市场共识已经高度一致，哪些变量仍存在显著分歧。

理解市场定价不能只依赖券商目标价，应结合一致预期、估值、预测修订和事件后的价格反应。

### 5.4 设计悲观、基准和乐观情景

情景必须对应不同的产业路径，而不是机械地把收入和利润上下调整固定比例。

#### 悲观情景

可能包括：

- 需求推迟；
- 客户资本开支下修；
- 技术验证慢于预期；
- 供给快速扩张；
- 价格竞争加剧；
- 公司份额下降；
- 毛利率承压；
- 存货和折旧压力增加；
- 市场给予更低估值中枢。

#### 基准情景

可能包括：

- 需求按照当前指引增长；
- 技术按计划导入；
- 供需基本匹配；
- 产品价格正常下降；
- 公司市场份额保持稳定；
- 毛利率符合正常产品结构变化；
- 估值回归合理中枢。

#### 乐观情景

可能包括：

- 客户预算和订单上修；
- 新产品提前量产；
- 供给瓶颈持续；
- 龙头份额提升；
- 产品结构改善；
- 毛利率高于市场预期；
- 现金流改善快于预期；
- 盈利上修与估值扩张同时发生。

情景概率可以使用定性权重或区间。资料不足时不要求精确概率，但必须说明当前最可能情景和置信度。

### 5.5 将行业假设映射至公司

对每家公司至少明确：

- 公司对哪些行业变量最敏感；
- 变量影响销量、价格、份额还是产品结构；
- 收入兑现存在多长时间差；
- 毛利率和费用率如何变化；
- 现金流和资本开支如何变化；
- 相关业务对公司整体是否足以产生实质影响；
- 公司相对竞争对手的盈利弹性更高还是更低。

### 5.6 形成团队盈利假设

在第四阶段一致预期底稿基础上，形成团队对未来一年和未来两年的：

- 分业务收入；
- 销量；
- 产品价格；
- 市场份额；
- 毛利率；
- 费用率；
- 扣非利润或EBITDA；
- 经营现金流；
- 资本开支；
- 股本和净现金。

每项关键预测应能够回溯至行业变量、公司经营指标和商业化证据，不能使用无法解释的机械增长率。

### 5.7 反向校验市场隐含预期

对拟重点讨论的公司，至少进行一种反向校验：

- 以当前市值和合理估值倍数反推未来利润；
- 以当前PS或EV/Sales反推市场要求的收入增速和利润率；
- 以产能、份额和单价反推当前价格隐含的经营规模；
- 对现金流稳定公司使用反向DCF；
- 对多元化公司反推各分部隐含价值。

反推结果应与以下事项比较：

- 行业市场空间；
- 公司产能；
- 历史执行能力；
- 客户和订单证据；
- 竞争对手表现；
- 市场一致预期。

### 5.8 选择估值方法

根据公司商业模式和发展阶段选择：

| 公司特征 | 主要估值方法 | 使用注意 |
|---|---|---|
| 盈利稳定的成长公司 | Forward PE、PEG | 增长和盈利质量必须与倍数匹配 |
| 尚未盈利或仍处投入期 | PS、EV/Sales | 结合单位经济性、现金消耗和盈利拐点 |
| 重资产或周期公司 | EV/EBITDA、PB | 考虑周期中枢和资产回报 |
| 多元化集团 | 分部估值 | 分别匹配各业务的可比公司和方法 |
| 现金流稳定公司 | DCF | 重点检查长期增长、资本开支和折现率 |
| 高不确定性项目 | 情景估值 | 避免单点预测造成虚假精确 |

### 5.9 形成情景估值

每家公司至少形成：

| 情景 | 盈利假设 | 估值方法 | 估值倍数或参数 | 合理市值 | 相对当前空间 | 成立条件 |
|---|---|---|---|---|---|---|
| 悲观 | 需求、份额或利润率承压 | 按公司特征选择 | 较低倍数或保守参数 | 待测算 | 待测算 | 悲观路径成立 |
| 基准 | 按团队核心假设 | 按公司特征选择 | 合理中枢 | 待测算 | 待测算 | 基准假设兑现 |
| 乐观 | 订单、份额和利润率超预期 | 按公司特征选择 | 合理溢价 | 待测算 | 待测算 | 乐观催化兑现 |

估值结果应同时展示：

- 上行空间；
- 下行空间；
- 基准情景回报；
- 主要估值敏感变量；
- 估值实现所需时间。

### 5.10 建立《公司比较与估值矩阵》

全部正式标的均进入统一矩阵。

建议字段包括：

| 类别 | 主要字段 |
|---|---|
| 公司身份 | 公司名称、证券代码、产业链节点 |
| 行业暴露 | 相关业务占比、主要受益路径 |
| 竞争位置 | 技术、客户、产能、成本、份额趋势 |
| 财务表现 | 收入增速、利润增速、毛利率、现金流 |
| 盈利敏感性 | 对需求、价格、份额、毛利率的敏感程度 |
| 当前估值 | Forward PE、PS、EV/EBITDA等 |
| 团队估值 | 悲观、基准和乐观估值 |
| 市场预期 | 当前价格隐含的增长和利润假设 |
| 盈利修订 | 市场预测上修、下修或稳定 |
| 预期差 | 团队判断与市场预期的差异 |
| 收益来源 | 盈利增长、盈利上修、估值修复、估值扩张或分红回购 |
| 时间范围 | 预计验证和兑现时间 |
| 下行风险 | 悲观情景和主要损失来源 |
| 催化剂 | 订单、产品、客户、产能、价格、政策等 |
| 当前结论 | 进入投资决策、等待验证、暂不参与或排除 |

### 5.11 识别预期差

预期差分析至少回答：

1. 市场目前相信什么；
2. 市场通过哪些盈利预测、估值和价格反应体现该预期；
3. 团队与市场在哪个变量上不同；
4. 团队判断的事实和证据是什么；
5. 差异如何影响收入、利润、现金流和合理估值；
6. 哪些事件可能让市场重新定价；
7. 预期差是否可能长期存在而缺乏催化；
8. 当前风险收益是否足以形成投资命题。

### 5.12 评估收益来源、时间路径和风险收益

对拟形成命题的公司必须说明：

- 预期收益主要来自什么；
- 盈利和估值各贡献多少；
- 预计验证窗口和兑现期限；
- 悲观情景的下行空间；
- 上行与下行是否具有不对称性；
- 命题是否依赖单一事件；
- 在没有估值扩张的情况下，盈利增长能否支持回报；
- 如果催化延迟，命题是否仍然成立。

可以使用概率加权估值，但不是强制要求。无论是否赋予概率，都必须明确主情景、替代情景和置信度。

### 5.13 形成投资命题

只有同时满足以下条件，才形成正式投资命题：

- 存在清晰预期差；
- 预期差有事实和逻辑支持；
- 预期差能够影响盈利和估值；
- 当前价格尚未完全反映团队判断；
- 存在合理催化剂或收敛路径；
- 时间范围明确；
- 悲观情景和下行风险明确；
- 反证条件明确；
- 风险收益具有讨论价值。

### 5.14 形成行业层面结论

项目总负责人综合全部公司结论，判断：

- 行业整体是否值得参与；
- 行业当前处于结构性成长、周期上行、短期补库存还是主题交易；
- 哪些产业链环节更具吸引力；
- 当前机会来自盈利增长、盈利修订、估值修复还是估值扩张；
- 行业整体风险是否已经被充分定价；
- 哪些关键指标最可能推动行业重新定价；
- 是否存在行业整体高估、盈利兑现不足或缺乏合适标的的问题。

如果行业没有合适机会，应形成明确的否定性行业命题，并记录重新评估条件。

- 审核《投资命题卡》；
- 完成本阶段验收。

### 7.2 组员

组员负责所覆盖公司的：

- 经营假设；
- 假设依据；
- 盈利敏感性；
- 情景盈利；
- 情景估值；
- 市场隐含预期；
- 预期差；
- 催化剂；
- 主要风险；
- 投资命题草案；
- 根据团队讨论修正结论。

### 7.3 AI工具

AI工具可以辅助：

- 更新公司财务和估值数据；
- 汇总市场一致预期；
- 生成团队假设表初稿；
- 生成情景测算模板；
- 计算公司盈利敏感性；

AI工具不得独立决定：

- 情景是否符合真实产业路径；
- 公司盈利假设是否合理；
- 估值倍数是否合理；
- 市场共识是否被准确理解；
- 预期差是否真实存在；
- 是否形成投资命题。

## 八、验收标准

### 8.1 行业判断完整

- 行业阶段明确；
- 结构性趋势、周期性变化和短期事件得到区分；
- 未来一至两年核心驱动明确；
- 需求、供给、技术和价格判断一致；
- 价值量和利润迁移方向明确；
- 行业催化和风险明确。

### 8.2 市场定价理解充分

- 市场当前主流叙事明确；
- 市场最关注的经营指标明确；
- 盈利预测上修或下修方向明确；
- 估值处于扩张、收缩还是分化阶段得到说明；
- 重大事件后的价格反应得到分析；
- 市场预期不是仅由券商目标价代替。

### 8.3 团队假设可追溯

- 关键变量有事实基础；
- 公司指引、市场预期和团队假设得到区分；
- 每项假设有悲观、基准和乐观情景；
- 每项假设有置信度和验证指标；
- 主要分歧得到记录。

### 8.4 盈利映射和反向校验合理

- 行业变量能够映射至公司销量、价格、份额和利润率；
- 相关业务对公司整体影响得到考虑；
- 收入、利润和现金流的时间差得到说明；
- 不使用无法解释的机械增长率；
- 当前价格隐含的利润、收入或份额要求得到反向校验；
- 隐含要求与行业空间、产能和公司执行能力进行比较。

### 8.5 估值方法合理

- 估值方法与公司商业模式匹配；
- 估值基准日期明确；
- 盈利和股本口径一致；
- 历史和可比公司估值使用合理；
- 悲观、基准和乐观估值均有成立条件；
- 上行、下行、敏感变量和预计实现时间明确。

### 8.6 公司比较完整

- 全部正式标的进入比较矩阵；
- 不只比较少数热门公司；
- 公司之间使用可比较口径；
- 竞争、财务、估值、盈利修订和风险得到综合比较；
- 收益来源和时间路径得到说明。

### 8.7 预期差真实

- 市场预期得到明确描述；
- 团队分歧落在具体变量上；
- 预期差有证据支持；
- 预期差能够影响盈利和估值；
- 当前价格尚未完全反映团队判断；
- 验证路径和时间窗口明确。

### 8.8 投资命题可证伪且风险收益清晰

- 命题包含事实、推断和假设；
- 收益来源明确；
- 时间范围明确；
- 催化剂明确；
- 悲观情景和下行空间明确；
- 反证条件明确；
- 重新评估条件明确；
- 不以“长期看好”代替可验证命题。

### 8.9 允许否定性结论并保持阶段边界

- 没有投资机会时明确记录；
- 暂不参与的原因明确；
- 行业、公司、市场预期和估值问题得到区分；
- 重新评估条件明确；
- 本阶段不讨论实际仓位、交易时点、止盈止损和组合风险预算。

## 九、团队假设与情景设计原则

### 9.1 事实、市场预期和团队假设必须分开

团队讨论中必须明确：

- 什么是已经发生的事实；
- 什么是公司或券商的预测；
- 什么是市场一致预期；
- 什么是团队自己的判断。

### 9.2 情景必须对应真实产业路径

情景之间应反映：

- 不同需求路径；
- 不同技术导入速度；
- 不同供给释放；
- 不同价格竞争；
- 不同公司份额；
- 不同利润率变化。

### 9.3 不追求虚假精确

当信息不足时，可以使用：

- 区间；
- 情景；
- 概率性判断；
- 高、中、低置信度。

不应为了模型完整而人为制造精确数字。

### 9.4 分歧必须可定位

如果成员观点不同，应明确分歧来自：

- 数据；
- 需求假设；
- 技术路线；
- 供给；
- 份额；
- 利润率；
- 估值倍数；
- 催化时间。

### 9.5 市场一致预期必须有可观察依据

市场一致预期可以来自：

- 盈利预测中位数和变化；
- 公司指引；
- 当前估值和可比公司；
- 重大事件后的价格反应；
- 公开持仓和资金数据；
- 主流研究叙事。

不能仅凭研究员主观判断写“市场尚未预期”或“市场已经充分定价”。

### 9.6 价格反应是市场理解的重要证据

当公司发布订单、财报或产品信息后，应观察：

- 股价反应方向和幅度；
- 盈利预测是否同步调整；
- 估值倍数是否变化；
- 同行业公司是否同步反应；
- 市场真正关注的是收入、利润率、现金流还是远期故事。

价格反应不能证明基本面判断正确，但可以帮助理解市场当前的定价变量。

## 十、盈利与估值设计原则

### 10.1 盈利预测以前一阶段事实为基础

不得重新虚构：

- 客户；
- 订单；
- 产能；
- 产品；
- 收入结构；
- 市场份额。

### 10.2 估值方法必须与商业模式匹配

不要求所有公司统一使用PE，也不应为了可比而忽略公司阶段差异。

### 10.3 估值倍数必须解释

合理倍数应结合：

- 增长速度；
- 盈利质量；
- 现金流；
- ROE或ROIC；
- 技术和客户壁垒；
- 行业周期；
- 预测确定性；
- 治理和外部风险。

### 10.4 估值前提必须可以验证

情景估值应说明：

- 什么假设使公司值得更高倍数；
- 什么风险会导致估值中枢下降；
- 当前市场已经计价多少。

### 10.5 估值必须同时呈现收益来源和下行风险

估值结论应拆分：

- 未来回报中有多少来自盈利增长；
- 有多少来自盈利预测上修；
- 有多少来自估值修复或扩张；
- 在估值不扩张时是否仍有合理回报；
- 悲观情景下可能损失多少；
- 哪些变量对上行和下行最敏感。

### 10.6 优先进行反向估值而非只给目标倍数

对于拟形成正式命题的公司，应尽可能反推当前价格要求公司实现什么收入、利润、份额和资本回报，以检验团队所谓“预期差”是否真实存在。

---

## 十一、投资命题设计原则

### 11.1 命题必须围绕预期差

投资命题不是公司介绍，也不是长期行业故事。

### 11.2 命题必须能够被市场验证

需要有明确的：

- 财报；
- 订单；
- 产品；
- 客户；
- 产能；
- 价格；
- 政策；
- 行业数据。

### 11.3 命题必须允许被推翻

不能把所有负面信息都解释为短期扰动。

### 11.4 好公司不等于好投资

如果估值已经充分反映增长，即使公司基本面良好，也可以结论为“暂不参与”。

### 11.5 无命题也是有效结论

公司可以被完整覆盖，但当前不具备可操作预期差。

---

## 十二、会议与工作节奏

本阶段建议通过两次核心会议完成。

### 12.1 第一次会议：行业假设会议

#### 会前

- 项目总负责人形成假设表初稿；
- 各成员检查所覆盖公司的敏感变量；
- 各成员提出需要修正的行业假设；
- 项目总负责人汇总市场一致预期、盈利预测修订和近期价格反应。

#### 会中

- 统一行业阶段判断；
- 统一关键需求、供给、技术和价格变量；
- 形成悲观、基准和乐观情景；
- 记录成员分歧；
- 明确市场当前定价框架；
- 明确待验证假设。

#### 会后

- 各成员将行业假设映射至公司盈利；
- 完成初步情景盈利和估值。

### 12.2 第二次会议：公司比较与投资命题会议

#### 会前

- 各成员完成所覆盖公司的情景盈利；
- 完成估值区间；
- 判断市场预期和盈利修订方向；
- 完成反向估值或隐含预期校验；
- 草拟预期差、收益来源、下行情景和投资命题。

#### 会中

- 横向比较全部公司；
- 检查估值口径；
- 讨论预期差；
- 讨论收益来源、验证时间、催化剂、下行风险和反证；
- 决定哪些公司形成投资命题；
- 记录暂不参与或排除原因。

#### 会后

- 项目总负责人整合《行业综合投资判断》；
- 完成《公司比较与估值矩阵》；
- 完成《投资命题卡》。

行业复杂或公司数量较多时，可以增加一次中间校验会议，但不应为了流程完整而机械增加会议。

## 十三、自动化潜力

### 13.1 适合自动化的内容

- 同步公司财务和估值数据；
- 更新一致预期和盈利预测修订；
- 汇总重大事件后的价格反应；
- 生成假设表初稿；
- 生成三情景测算模板；
- 计算盈利敏感性；
- 进行简化反向估值和隐含预期测算；
- 生成公司比较矩阵；
- 检查估值口径；
- 生成投资命题卡初稿；
- 提醒缺少催化剂、风险或反证条件。

### 13.2 适合Prompt工具包的内容

可以建立：

1. 团队假设生成与检查Prompt；
2. 三情景设计Prompt；
3. 行业变量到公司盈利映射Prompt；
4. 盈利敏感性分析Prompt；
5. 估值方法选择Prompt；
6. 公司横向比较Prompt；
7. 市场隐含预期与反向估值Prompt；
8. 盈利预测修订和价格反应分析Prompt；

11. 投资命题卡生成Prompt；
12. 反证条件检查Prompt。

### 13.3 必须人工判断的内容

- 团队核心假设；
- 情景合理性；
- 盈利预测；
- 估值倍数；
- 市场共识；
- 预期差；
- 投资命题；
- 命题置信度。

## 十四、异常处理

### 14.1 团队假设无法统一

保留主情景和异议情景，明确分歧变量及验证条件，不强行形成表面共识。

### 14.2 市场一致预期缺失

使用公司指引、历史数据和可比公司区间，不虚构精确共识。

### 14.3 公司无法形成可靠盈利预测

使用情景区间、PS、资产价值或其他替代方法，并降低命题置信度。

### 14.4 估值方法差异过大

说明不同方法的适用条件，保留估值区间，不追求唯一估值。

### 14.5 公司基本面良好但估值充分

记录为“暂不参与”，明确什么价格或盈利变化后重新评估。

### 14.6 行业没有合适投资机会

形成否定性行业命题，说明问题来自：

- 行业需求；
- 公司质量；
- 盈利兑现；
- 估值；
- 风险收益。

### 14.7 投资命题缺乏催化

可以保留长期观察，但不直接进入投资决策。

### 14.8 投资命题出现关键反证

及时降低置信度、修改或取消命题，不等待项目结项后处理。

---

## 十五、本阶段不负责的事项

本阶段不负责：

- 实际买入或卖出；
- 仓位大小；
- 组合风险预算；
- 交易时点；
- 止盈止损；
- 持仓间相关性管理；
- 长期动态跟踪任务的执行；
- 交易与组合复盘。

上述内容进入下一阶段“投资决策与组合管理”，以及之后的动态跟踪与复盘阶段。

---

## 十六、本阶段完成定义

团队假设、行业综合判断与投资命题形成阶段完成，应达到以下状态：

> 团队已经基于前四阶段形成的行业和公司事实底稿，对行业未来一至两年的需求、供给、技术、价格和竞争变量形成了可追溯的共同假设；建立了悲观、基准和乐观情景；将行业假设映射至公司盈利、现金流和合理估值；对全部正式标的完成横向比较；明确了市场预期与团队判断之间的差异；对具备预期差、催化剂和验证条件的公司形成了可证伪投资命题；对不具备机会的公司或行业形成了等待、暂不参与或否定性结论，可以进入投资决策与组合管理阶段。
