## 一、阶段定位

本阶段承接第三阶段形成的行业认知和产业链结构，将行业研究进一步落实到具体公司。

本阶段由两个紧密联系的子流程组成：

1. **标的池建立与维护**：确认产业链上有哪些实质相关公司，并将公司实体、证券代码和产业链位置统一管理；
2. **公司标准化全覆盖**：对所有正式入池公司形成统一格式、达到最低研究标准的公司报告。

本阶段的公司覆盖不再是简单基础档案，而是一份能够直接进入后续投资讨论的标准化研究底稿。每家公司至少需要完成四个核心模块：

1. 行业现状与公司映射；
2. 公司竞争格局；
3. 公司财务状况；
4. 公司估值水平。

四个模块形成一条完整逻辑：

> 行业变化是否存在  
> → 公司能否获得竞争优势  
> → 优势是否已经转化为收入、利润和现金流  
> → 当前市场价格反映了多少未来预期。

本阶段不直接形成正式买卖建议，也不要求团队在此阶段对盈利假设、目标价和仓位形成共识。后续阶段应基于本阶段的统一底稿讨论：

- 哪些假设可以采纳；
- 哪些市场预期存在偏差；
- 公司合理盈利和估值区间；
- 是否能够形成投资命题。

## 二、阶段起点与终点

### 2.1 阶段起点

本阶段从第三阶段通过验收并形成《下一阶段交接说明》后开始。

进入本阶段前，应至少满足：

- 行业研究主文档已经完成；
- 产业链图和关键节点已经明确；
- 需要覆盖的产业链环节已经确定；
- 每个环节的产品、技术和业务关键词已经确定；
- 目标市场和地区已经明确；
- 公司覆盖所需的行业特定字段已经初步说明；
- 当前发现的公司线索已经完成交接。

### 2.2 阶段终点

本阶段只有在以下事项全部完成后才算结束：

- 标的池边界和公司入池标准已经明确；
- 主要产业链节点均已完成公司搜集；
- 公司实体、母子关系和多地上市关系已经去重；
- 所有正式标的均已映射至至少一个产业链节点；
- 所有正式入池公司均已形成《公司标准化研究报告》；
- 每份报告均完成行业现状、竞争格局、财务状况和估值水平四个模块；
- 产品、客户、认证、订单、交付和收入确认状态已经使用统一口径；
- 公司商业模式、单位经济性、治理和资本配置已经达到最低覆盖要求；
- Sentinel自动生成内容已经完成人工复核；
- 关键事实、市场一致预期和研究判断已经区分；
- 资料缺口和冲突信息已经明确记录；
- 行业标的主表中的覆盖状态和报告链接已经更新；
- 项目总负责人确认报告足以支持后续团队假设和投资讨论。

## 三、目标

### 3.1 建立完整、可维护的标的池

标的池应覆盖项目产业链范围内具有真实业务关联的主要可投资公司，并保留关键非上市参与者作为行业参考主体。

标的池不以市场热度、股价表现或券商关注度决定公司是否入池。

### 3.2 明确公司与行业变化之间的传导关系

每家公司都需要说明：

- 公司位于产业链什么位置；
- 相关产品和业务是什么；
- 行业需求如何传导至公司订单、收入和利润；
- 技术路线变化对公司是利好、利空还是中性；
- 相关业务对公司整体是否具有实质影响。

### 3.3 判断公司能否在行业变化中获得份额和利润

需要通过竞争格局分析判断：

- 公司面对哪些直接竞争对手；
- 公司技术、产品、客户、产能、成本或供应链优势是否真实；
- 公司优势是否具备持续性；
- 公司是否存在份额提升、利润率改善或竞争地位下降的可能。

### 3.4 用财务数据验证产业逻辑

公司财务分析必须验证：

- 行业需求是否已经转化为收入；
- 产品升级是否带来毛利率或产品结构改善；
- 订单增长是否转化为现金流；
- 扩产是否有效形成产能和销售；
- 公司增长是否依赖非经常性损益、并购或会计处理；
- 资产负债表是否存在明显风险。

### 3.5 建立统一估值底稿

每家公司应形成可比较的估值基础，包括：

- 当前市值和企业价值；
- 历史估值水平；
- 市场一致预期；
- 可比公司估值；
- 适用的估值方法；
- 当前估值隐含的主要增长预期。

本阶段的估值模块用于描述“市场目前如何定价”，不直接形成团队最终目标价。

### 3.6 建立商业化证据链和市场认知

每家公司需要建立从技术到财务的证据链：

> 技术或产品能力 → 客户验证 → 订单或采购 → 交付 → 收入确认 → 毛利润 → 现金回款 → 复购与份额。

同时需要说明：

- 公司当前主要市场叙事是什么；
- 市场最关注哪些经营指标；
- 哪些信息属于公司披露、第三方估计或市场传闻；
- 哪些变量会驱动盈利预测和估值变化。

### 3.7 降低后续环节的重复劳动

公司标准化研究报告应尽量提前解决事实和数据问题，使后续团队会议主要讨论：

- 关键假设；
- 分歧；
- 预期差；
- 合理估值；
- 风险收益；
- 投资命题。

后续阶段不应重新从头搜集公司业务、竞争和财务资料。

## 四、输入

### 4.1 第三阶段研究成果

包括：

- 《行业研究主文档》；
- 技术路线对比表；
- 产业链图和关键节点说明；
- 《下一阶段交接说明》；
- 行业特定产品、技术和业务关键词。

### 4.2 《长期产业地图主表》

用于：

- 将公司挂接至正式产业节点；
- 复用跨项目公司资料；
- 避免同一公司重复建档；
- 管理公司与多个行业节点之间的关系。

### 4.3 公司法定与官方资料

优先包括：

- 年报和中期报告；
- 招股书；
- 公司公告；
- 投资者关系活动记录；
- 公司官网和产品手册；
- 业绩说明会；
- 客户或供应商公开披露；
- 交易所资料。

### 4.4 外部公司与行业资料

包括：

- 行业协会和标准组织资料；
- 券商研报；
- 专业行业数据库；
- 市场份额和出货量资料；
- 竞争对手披露；
- 专利和认证资料；
- 新闻与产业媒体；
- 专家和会议资料。

外部资料应与公司法定披露区分使用。

### 4.5 财务与市场数据

包括：

- 历史财务报表；
- 分业务、分产品和分地区数据；
- 季度和年度数据；
- 市值和股价；
- 一致预期；
- 历史估值；
- 可比公司估值；
- 机构盈利预测。

### 4.6 Sentinel及公司研究模板

Sentinel应支持：

- 公司发现；
- 实体识别与去重；
- 年报和公告下载；
- 财务字段提取；
- 产品、客户、订单和产能信息提取；
- 估值数据接入；
- 行业特定字段配置；
- 公司报告初稿生成；
- 来源和引用位置保留。

## 五、主要动作

本阶段按照两个子流程执行。

# A. 标的池建立与维护

### 5.1 确定标的池边界

项目总负责人根据第三阶段交接说明明确：

- 覆盖的产业链节点；
- 覆盖的上市市场和地区；
- 是否包含客户、平台方和系统厂商；
- 是否包含上游材料和设备公司；
- 非上市主体如何记录；
- 什么程度的业务关联可以正式入池；
- 哪些通用环节不纳入本项目。

### 5.2 发现并汇总公司

公司来源包括：

- 第三阶段发现的参与者；
- Sentinel关键词检索；
- 上下游公司披露；
- 客户与供应商名单；
- 交易所和行业分类；
- 行业协会、标准组织和展会；
- 年报和招股书中的竞争对手；
- 既有项目中的公司档案；
- 研究成员补充。

发现阶段优先提高召回率，暂时无法确认的公司进入“相关性待确认”。

### 5.3 完成公司实体标准化

需要处理：

- 中文名、英文名、简称和历史名称；
- 母公司与经营子公司；
- 品牌与经营主体；
- A股、港股、美股和ADR；
- 收购、分拆、更名和退市；
- 同一集团下不同业务主体。

原则上：

- 一个实际经营主体使用一个 `company_id`；
- 一个公司实体可以对应多个证券；
- 不因多地上市重复建立公司研究报告。

### 5.4 确认业务相关性

每家公司至少检查：

- 相关产品或服务；
- 对应产业链节点；
- 商业化阶段；
- 客户、订单、收入或产能证据；
- 相关业务对公司的重要程度；
- 是否只有概念性布局；
- 是否应作为正式标的、行业参考主体、待确认公司或排除对象。

处理结果统一为：

- 正式入池；
- 行业参考主体；
- 相关性待确认；
- 排除。

### 5.5 建立《行业标的主表》

每个公司实体一行，至少包含：

| 字段 | 内容要求 |
|---|---|
| company_id | 公司实体唯一编号 |
| company_name | 公司标准名称 |
| aliases | 英文名、简称、旧称和品牌名 |
| securities | 证券代码及上市市场 |
| listing_status | 上市、非上市、已退市或其他 |
| headquarters | 总部地区 |
| related_nodes | 对应产业链节点 |
| relevant_products | 相关产品或服务 |
| relevance_basis | 入池依据 |
| commercialization_stage | 研发、送样、验证、小批量、量产等 |
| business_materiality | 相关业务对公司的重要程度 |
| coverage_type | 正式标的或行业参考主体 |
| coverage_status | 当前覆盖状态 |
| assigned_member | 人工复核负责人 |
| latest_update | 最近更新时间 |
| report_link | 公司标准化研究报告位置 |
| missing_fields | 主要资料缺口 |
| exclusion_reason | 排除时填写 |
| notes | 其他说明 |

# B. 公司标准化全覆盖

### 5.6 生成公司研究初稿

Sentinel根据统一模板批量生成初稿，至少完成：

- 公司基本信息；
- 业务和收入结构；
- 产业链位置；
- 产品与技术；
- 商业化进度；
- 客户、订单与产能披露；
- 历史财务数据；
- 当前估值和一致预期；
- 资料来源；
- 缺失字段和冲突信息。

生成后，公司覆盖状态更新为“待人工复核”。

### 5.7 完成人工复核

组员负责：

- 核实公司实体和证券关系；
- 确认产业链位置；
- 核实产品、客户、订单和商业化阶段；
- 检查财务数据的期间、币种和单位；
- 删除无依据的AI推断；
- 补充自动提取遗漏的信息；
- 形成竞争位置和财务质量判断；
- 检查估值口径；
- 记录待讨论假设；
- 补充References。

人工复核不是重新撰写整份报告，而是对事实、逻辑和判断负责。

### 5.8 统一产品、客户、订单与商业化状态

为了避免将“布局”“送样”“合作”误写为订单和收入，所有公司统一使用以下状态：

1. 技术储备或概念研发；
2. 原型或工程样品；
3. 送样；
4. 客户测试或认证；
5. 进入供应商名单；
6. 小批量试用或试产；
7. 获得正式订单或采购合同；
8. 批量交付；
9. 收入确认；
10. 重复采购或份额扩大；
11. 规模化稳定贡献。

对每项产品、客户和订单信息至少记录：

- 对象是什么；
- 当前状态；
- 信息日期；
- 来源；
- 是否有数量、金额、产能或收入证据；
- 是否为公司口径、客户口径、第三方估计或市场传闻；
- 下一步验证条件。

框架协议、战略合作、意向订单和规划产能不得直接视为正式订单、交付或有效产能。

### 5.9 完成模块一：行业现状与公司映射

本模块不重复第三阶段的完整行业研究，而是回答“行业变化如何具体影响这家公司”。

至少包括：

#### 5.9.1 公司本质与商业模式

- 公司本质上是什么类型的企业；
- 主要产品、服务和商业模式；
- 主要客户和下游；
- 收入和利润主要来自哪里；
- 公司相关业务是主营、第二增长曲线还是概念性布局；
- 收入来自产品销售、项目、订阅、授权、服务、耗材还是平台抽成；
- 收入是否可重复，客户获取和交付是否具有规模效应；
- 单位经济性、合同周期、回款周期和售后责任；
- 商业模式是否依赖补贴、一次性项目或单一客户。

#### 5.9.2 产业链位置

- 公司位于哪些产业链节点；
- 向上游采购什么；
- 向下游销售什么；
- 公司在最终系统中提供什么价值；
- 公司是否跨多个环节或进行纵向一体化。

#### 5.9.3 行业现状与公司暴露

- 所在细分行业当前处于什么阶段；
- 主要需求和技术变化；
- 相关业务市场空间与增长驱动；
- 行业需求如何传导至公司；
- 公司受益或受损的具体路径；
- 行业变化对公司收入、利润和现金流影响的时间差。

#### 5.9.4 产品、客户与商业化状态

- 主要相关产品及规格；
- 研发、送样、验证、小批量和量产状态；
- 客户认证和导入周期；
- 当前收入贡献；
- 未来扩产和交付计划；
- 尚未兑现的技术和产品布局。

#### 5.9.5 订单、交付与收入转化

分析：

- 新签订单、在手订单和订单覆盖周期；
- 订单是否可取消、是否具有框架性质；
- 客户验证转正式采购的转化率；
- 订单到生产、交付、验收和收入确认的周期；
- 交付是否受产能、良率、关键材料或客户排期限制；
- 收入增长是否同步转化为毛利润、经营现金流和复购；
- 公司是否存在提前备货、渠道压货或项目验收波动。

#### 5.9.6 本模块结论

至少回答：

- 公司与行业的相关性是否真实；
- 行业逻辑能否传导至公司；
- 相关业务是否足以影响公司整体；
- 兑现需要观察哪些指标。

### 5.10 完成模块二：竞争格局

本模块以目标公司为中心，而不是重新撰写行业竞争史。

至少包括：

#### 5.10.1 竞争对手范围与行业结构

- 直接竞争对手；
- 替代技术或替代产品提供者；
- 国内与海外竞争者；
- 潜在新进入者；
- 客户自研或垂直整合风险。

#### 5.10.2 公司竞争位置与市场份额

比较维度包括：

- 市场份额和行业排名；
- 产品规格与性能；
- 技术路线；
- 研发能力；
- 客户资源；
- 客户验证阶段；
- 订单和交付能力；
- 产能和良率；
- 成本和价格；
- 供应链控制；
- 海外产能和市场；
- 标准、专利和生态地位。

#### 5.10.3 客户资源与生态地位

分析：

- 核心客户数量和质量；
- 是否进入正式供应商名单；
- 客户认证周期和转换成本；
- 客户集中度和大客户依赖；
- 客户是否由试点转向重复采购；
- 公司在标准、生态、平台或系统集成中的位置；
- 客户自研和纵向一体化对公司的影响。

#### 5.10.4 成本优势与供应链控制

分析：

- 核心成本和关键供应商；
- 自制率、纵向一体化和多供应商能力；
- 良率、规模效应和自动化对成本的影响；
- 海外供应依赖和出口限制；
- 成本优势能否转化为价格、份额或毛利率优势；
- 竞争优势是否依赖阶段性短缺。

#### 5.10.5 商业模式与盈利能力比较

分析：

- 公司与竞争对手的收入模式；
- 标准化产品和定制项目占比；
- 毛利率、回款周期和资本强度差异；
- 规模效应和复购能力；
- 商业模式是否支持更高估值；
- 公司份额提升是否以低价和牺牲回报为代价。

#### 5.10.6 竞争优势验证

对每项竞争优势说明：

- 优势是什么；
- 证据是什么；
- 是否已经转化为客户、订单、收入或利润；
- 是否容易被模仿；
- 持续时间可能多长；
- 竞争对手如何追赶。

不接受仅以“技术领先”“客户优质”“行业龙头”等标签代替分析。

#### 5.10.7 竞争劣势与份额风险

包括：

- 技术落后；
- 产品结构较差；
- 客户过度集中；
- 成本较高；
- 产能不足或过剩；
- 供应链受限；
- 海外准入风险；
- 客户自研；
- 替代路线；
- 价格竞争。

#### 5.10.8 本模块结论

至少回答：

- 公司当前处于什么竞争位置；
- 优势主要来自哪里；
- 优势是否可持续；
- 未来份额更可能提升、稳定还是下降；
- 份额变化能否转化为利润改善。

### 5.11 完成模块三：财务状况

财务分析应覆盖至少过去三年、最新一期及市场可获得的未来一致预期。

#### 5.11.1 收入结构与增长来源

分析：

- 分业务、分产品、分行业和分地区收入；
- 各业务收入占比和增速；
- 新旧业务变化；
- 收入增长来自销量、价格、产品结构、并购还是项目确认；
- 订单、交付和收入确认之间的关系；
- 客户集中度；
- 海外与国内收入变化。

#### 5.11.2 毛利润和成本结构

分析：

- 分业务毛利率；
- 各业务毛利润贡献；
- 毛利率变化原因；
- 原材料、人工、折旧和外协成本；
- 产品升级、规模效应和价格竞争影响；
- 哪些业务贡献收入，哪些业务真正贡献毛利润。

#### 5.11.3 费用与研发

分析：

- 销售、管理、研发和财务费用率；
- 研发投入规模与方向；
- 研发资本化；
- 股权激励；
- 费用率变化；
- 研发成果是否形成产品和收入。

#### 5.11.4 利润质量

分析：

- 归母净利润与扣非净利润；
- 非经常性损益；
- 政府补助；
- 公允价值变动；
- 资产处置；
- 并购影响；
- 盈利拐点是否真实；
- 利润增长是否来自主营业务。

#### 5.11.5 现金流与营运资本

分析：

- 经营现金流；
- 净利润现金含量；
- 应收账款；
- 合同资产；
- 存货；
- 预付款和应付款；
- 回款周期；
- 备货和库存减值风险；
- 订单增长是否真正转化为现金流。

#### 5.11.6 资产负债与资本开支

分析：

- 现金和有息负债；
- 资产负债率；
- 短期偿债能力；
- 固定资产和在建工程；
- 资本开支；
- 扩产进度；
- 商誉和无形资产；
- 减值风险；
- 融资和稀释风险。

#### 5.11.7 经营效率与回报

分析：

- ROE；
- ROIC；
- 总资产周转率；
- 存货和应收周转；
- 单位资本开支产出；
- 规模增长是否带来经营效率改善。

#### 5.11.8 管理层、治理与资本配置

分析：

- 管理层背景、稳定性和产业经验；
- 股权结构、实际控制人和利益一致性；
- 股权激励、员工持股和稀释影响；
- 历史指引和承诺兑现情况；
- 关联交易、担保和治理风险；
- 融资、并购、分红和回购；
- 资本开支与并购是否创造合理回报；
- 管理层是否存在追逐热点或频繁改变战略的问题。

#### 5.11.9 财务预测桥梁与关键经营指标

建立从经营指标到财务数据的桥梁：

- 订单或客户数量如何映射销量；
- 销量和价格如何映射收入；
- 产品结构、良率和成本如何映射毛利率；
- 产能、折旧和人员如何映射费用与利润；
- 应收、存货和资本开支如何映射现金流；
- 哪些经营指标最适合在下一阶段用于盈利预测。

#### 5.11.10 一致预期与业绩指引

记录：

- 公司指引；
- 市场一致预期；
- 收入和利润预测变化；
- 预测上修或下修；
- 未来一至两年的主要增长假设；
- 预测中最敏感的变量。

本阶段记录一致预期，不要求组员独立建立最终盈利预测模型。

#### 5.11.11 本模块结论

至少回答：

- 公司增长是否真实；
- 哪些业务贡献收入、利润和现金流；
- 盈利质量如何；
- 资产负债表是否健康；
- 扩产和资本开支是否合理；
- 当前财务表现是否支持行业和竞争优势判断。

### 5.12 完成模块四：估值水平

估值数据必须标明基准日期。

#### 5.12.1 基础市场数据

包括：

- 股价；
- 总股本；
- 市值；
- 企业价值；
- 净现金或净负债；
- 流动性；
- 主要上市证券之间的关系。

#### 5.12.2 当前估值

根据公司特征选择：

- PE；
- PEG；
- PS；
- EV/EBITDA；
- EV/Sales；
- PB；
- FCF Yield；
- 分部估值；
- 其他行业特定指标。

至少展示：

- TTM；
- 当年预期；
- Forward 1年；
- Forward 2年。

不适用的指标应说明原因。

#### 5.12.3 历史估值

分析：

- 近三年至五年估值区间；
- 当前历史分位；
- 历史高低点对应的行业和公司状态；
- 估值中枢变化原因；
- 当前公司是否与历史时期具有可比性。

#### 5.12.4 可比公司估值

可比公司选择应考虑：

- 产业链位置；
- 商业模式；
- 技术路线；
- 成长阶段；
- 盈利能力；
- 市场和地区；
- 财务质量。

记录：

- 可比公司估值倍数；
- 增长和利润率差异；
- 目标公司溢价或折价；
- 溢价或折价是否具有合理基础。

不得仅因证券代码所属行业相同就视为可比公司。

#### 5.12.5 市场叙事与盈利预期变化

分析：

- 市场当前主要交易什么逻辑；
- 过去数个季度盈利预测是上修还是下修；
- 哪些财报、订单或产品事件曾推动估值变化；
- 公司股价对收入、利润率、订单和资本开支的反应；
- 当前估值溢价来自行业、公司质量、稀缺性还是短期情绪；
- 市场关注的关键经营指标是什么；
- 当前叙事是否与公司真实财务贡献匹配。

#### 5.12.6 市场隐含预期与反向校验

分析当前估值大致要求公司实现什么：

- 收入增速；
- 利润增速；
- 毛利率；
- 市场份额；
- 产品放量；
- 客户导入；
- 资本回报。

本阶段至少应进行简化反向校验：以当前市值和合理估值倍数反推市场需要的收入、利润或份额，并与公司产能、行业空间和历史执行能力比较。现金流较稳定且资料充分的公司可以使用反向DCF。

#### 5.12.7 估值方法适用性

说明下一阶段更适合使用：

- 相对估值；
- PEG；
- DCF；
- 分部估值；
- 情景估值；
- 资产价值；
- 其他方法。

并说明选择原因和主要限制。

#### 5.12.8 本模块结论

至少回答：

- 当前估值处于什么水平；
- 相对历史和可比公司是溢价还是折价；
- 市场已经计价了哪些增长预期；
- 当前估值最依赖哪些假设；
- 下一阶段需要重点讨论哪些估值问题。

本阶段不形成最终目标价、评级或买卖建议。

### 5.13 形成公司结论摘要

报告首页或末尾应形成一页摘要，包括：

- 公司本质；
- 产业链位置；
- 行业传导路径；
- 核心竞争优势；
- 主要竞争劣势；
- 收入、利润和现金流来源；
- 当前估值状态；
- 三项主要风险；
- 三项待验证事项；
- 下一阶段需要讨论的关键假设。

摘要不是投资结论，而是团队讨论入口。

### 5.14 更新覆盖状态

统一状态为：

- 已发现；
- 相关性待确认；
- 正式入池；
- 行业参考主体；
- 自动初稿完成；
- 待人工复核；
- 需要补充；
- 覆盖完成；
- 暂停更新；
- 已排除。

状态只表示研究进度，不表示投资评级。

## 七、负责人

### 7.1 项目总负责人

负责：

### 7.2 组员

负责所分配公司的人工复核和分析，包括：

- 核实业务和产业链位置；
- 完成行业映射；
- 判断竞争位置；
- 分析财务质量；

- 删除无依据内容；
- 补充信息缺口；
- 形成公司结论摘要；
- 补充References；
- 更新覆盖状态。

公司分配应综合考虑公司数量、业务复杂度、数据可得性和语言，不要求简单平均数量。

### 7.3 Sentinel与AI工具

负责：

- 公司发现和实体匹配；
- 法定资料和公开资料下载；
- 财务数据和估值数据提取；
- 产品、客户、订单和产能信息提取；
- 初步竞争对手识别；
- 报告初稿生成；
- References和引用位置保存；
- 缺失字段和冲突信息提示；
- 后续基础数据更新。

AI不得独立决定：

- 公司竞争优势是否成立；
- 商业化是否真实；
- 财务质量好坏；
- 可比公司选择；
- 市场预期是否合理；
- 公司投资价值。

## 八、验收标准

### 8.1 标的池完整性

- 主要产业链节点均有公司覆盖；
- 目标市场主要可投资公司无明显遗漏；
- 关键海外和非上市参与者得到记录；
- 排除和待确认公司具有原因；
- 公司实体不存在明显重复；
- 受益公司、受损公司、客户、供应商和替代者均得到适当识别。

### 8.2 行业现状与商业模式模块合格

- 公司产业链位置明确；
- 相关产品和业务明确；
- 行业需求到公司收入和利润的传导路径明确；
- 相关业务对公司整体的重要程度明确；
- 商业模式、收入重复性、合同和回款特点明确；
- 研发、送样、验证、小批量、订单、交付和收入确认得到区分。

### 8.3 商业化证据链合格

- 关键产品和客户信息具有日期和来源；
- 战略合作、框架协议、意向订单和正式订单得到区分；
- 订单、交付、收入确认、现金回款和复购形成连续证据链；
- 规划产能和有效产能得到区分；
- 市场传闻未被直接视为事实。

### 8.4 竞争格局模块合格

- 直接竞争对手、替代技术、潜在进入者和客户自研风险明确；
- 市场份额和行业排名口径得到解释；
- 技术、产品、客户、成本、供应链和商业模式均有比较；
- 优势与订单、收入、毛利率或份额建立联系；
- 竞争劣势和份额风险得到说明；
- 不以简单标签代替分析。

### 8.5 财务模块合格

- 分业务收入、毛利润和现金流贡献得到分析；
- 增长来源得到拆分；
- 订单到收入和现金的转化得到检查；
- 费用、研发效率、扣非利润和非经常性损益得到检查；
- 应收、存货、合同资产和现金流风险得到分析；
- 产能、资本开支和折旧与业务增长建立联系；
- 经营指标与财务预测之间存在清晰桥梁；
- 数据期间、币种和单位准确。

### 8.6 管理层与资本配置合格

- 管理层执行记录和指引可信度得到检查；
- 股权结构、激励和稀释风险得到说明；
- 融资、并购、扩产、分红和回购得到评价；
- 治理和关联交易风险得到识别；
- 资本配置是否支持长期回报得到判断。

### 8.7 估值与市场理解模块合格

- 估值基准日期明确；
- 当前、历史和可比公司估值均有覆盖；
- 估值指标与公司商业模式匹配；
- 市场叙事和盈利预测上修或下修得到说明；
- 当前价格隐含的收入、利润、份额或回报要求得到反向校验；
- 不在本阶段强行形成目标价和买卖评级。

### 8.8 自动化与人工复核合格

- 所有正式报告均经过人工复核；
- AI推断没有被直接当作事实；
- 关键数据可以追溯；
- 公司披露、客户披露、第三方数据和市场传闻得到区分；
- 信息缺口和冲突得到明确标记。

### 8.9 后续衔接合格

每份报告应明确列出：

- 需要团队讨论的经营假设；
- 需要调整的一致预期；
- 适用估值方法；
- 可能的预期差；
- 关键风险；
- 可验证指标；
- 影响盈利和估值的最敏感变量。

后续阶段可以直接使用这些内容，不需要重新制作公司底稿。

---

## 九、全覆盖与研究深度原则

### 9.1 全覆盖不等于简略覆盖

所有正式标的都需要完成四个核心模块，不能只完成公司简介和财务摘要。

### 9.2 全覆盖不等于完全等篇幅

相关业务重要、公司复杂或信息丰富的标的可以形成更长报告；信息有限的公司可以较短，但必须明确缺失内容。

### 9.3 事实完整优先于观点鲜明

本阶段首先确保事实、口径和比较基础可靠。最终投资观点留给后续团队讨论。

### 9.4 估值前置但结论后置

估值数据、历史分位和可比公司在本阶段完成；盈利假设调整、合理估值和投资结论在下一阶段形成。

### 9.5 公司报告应可独立阅读

读者不依赖原行业报告，也应能够理解公司做什么、为何受行业影响、竞争地位如何、财务是否兑现以及当前估值处于什么水平。

### 9.6 分批覆盖与交叉检查

全覆盖应按产业链节点或公司批次推进。每个批次建议完成以下闭环：

1. Sentinel生成初稿；
2. 负责人完成人工复核；
3. 另一名成员进行快速交叉检查；
4. 项目总负责人处理重大口径和相关性争议；
5. 更新主表状态后进入下一批。

交叉检查不是新的管理层级，只检查：

- 是否错误理解公司业务；
- 是否混淆商业化状态；
- 是否遗漏重大财务或治理风险；
- 竞争对手和可比公司是否合理；
- 市场隐含预期是否被正确描述。

### 9.7 来源优先级与结论置信度

来源优先级原则上为：

1. 法定公告、年报、招股书和监管文件；
2. 客户、供应商和合作方的原始披露；
3. 公司官网、产品手册和业绩说明会；
4. 行业协会、标准组织和专业数据库；
5. 高质量券商和行业研究；
6. 新闻、专家和市场渠道；
7. 未经验证的市场传闻。

关键结论应根据来源质量、交叉验证程度和时间有效性标记高、中或低置信度。

## 十一、异常处理

### 11.1 公司缺少分业务披露

明确标记“无法拆分”，使用公司披露的最细口径。第三方测算只能作为参考，不得视为确定事实。

### 11.2 公司尚未盈利

以PS、EV/Sales、单位经济性、现金消耗和资金需求为主，并说明盈利拐点假设，不强行使用PE。

### 11.3 周期性或资产型公司

使用PB、EV/EBITDA、重置成本或周期中枢利润等方法，不机械套用成长股估值。

### 11.4 多元化集团

按照业务分部分析行业暴露和财务贡献，估值上优先考虑分部估值。

### 11.5 相关业务过小

仍可入池，但必须明确相关业务对整体收入、利润和估值的真实影响，避免将小规模业务放大为公司主逻辑。

### 11.6 一致预期缺失

使用公司指引、历史数据和情景区间记录市场预期基础，但不在本阶段自行形成唯一盈利预测。

### 11.7 估值异常

检查：

- 盈利基数；
- 非经常性损益；
- 净现金；
- 周期高低点；
- 并购；
- 股本变化；
- 会计口径；
- 市场流动性。

### 11.8 Sentinel报告过度推断

删除无来源判断，并记录错误类型，用于后续修改Prompt、字段规则或数据源。

## 十二、本阶段不负责的事项

本阶段不负责：

- 从标的池中筛选少数核心标的；
- 形成正式买入、卖出或评级；
- 达成团队最终经营假设；
- 建立最终盈利预测模型；
- 确定目标价和合理估值区间；
- 形成正式投资命题；
- 决定仓位和交易时点；
- 建立长期动态跟踪制度。

---

## 十三、本阶段完成定义

标的池建立与公司标准化全覆盖阶段完成，应达到以下状态：

> 团队已经建立完整、去重并与产业链节点准确映射的行业标的池；所有正式入池公司均已形成经过人工复核的标准化研究报告，系统覆盖行业现状、竞争格局、财务状况和估值水平；公司事实、市场预期、研究判断和信息缺口得到清楚区分；每份报告均明确了需要在下一阶段讨论的关键假设、预期差、估值问题和风险，可以直接作为团队形成投资命题的共同底稿。
