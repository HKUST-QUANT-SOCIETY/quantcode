## 已核对的接线及其边界

- Electron 主进程通过已保存的研究宿主连接发起 challenge → 本机 SSH agent 签名 → 宿主 verify。签名和 token 不进入 renderer；仅返回身份摘要。复用原 gateway 协议，个人宿主仍必须按成员隔离，未引入共享进程多成员切换。
- GitHub 两种登录动作转入 Electron 主进程，宿主 prepare/import 协议绑定当前完整 owner、登录、GitHub subject 与一次性 nonce。Web 不能把宿主 `gh` 称为本机凭据。
- GitGraph、Pop、部署及回执的原生身份查询移除旧 MCP 身份依赖，保留各宿主动作中的重验。较早的 `4696` 不代表最新接线；新的 Electron/GitGraph 已有下述观察结果，部署和回执仍需单独验收。
- 现有 0755 宿主凭据目录保持兼容，拒绝组/其他用户可写目录；凭据文件仍必须 0600，并使用稳定句柄、no-follow、锁及原子写入。
