# 统一管理员登录

管理员只有一个身份和一次登录，不区分「工作身份」和「运维身份」。管理员登录后进入完整 QuantCode 工作台，拥有管理员角色覆盖的全部功能；组织管理和服务器状态是工作台中的功能页面。

## 成员与管理员

- 组员：选择本地私钥，按名册授权组进入相应工作区。
- 管理员：选择本地私钥，应用识别管理员后显示一个「管理员登录 · 全部权限」入口。完成正式 SSH 签名认证并核验 `role=admin` 后进入完整工作台。

管理员保留研究、任务历史、方案、Memory、能力目录、GitGraph、审批、发布和服务器页面。服务器切换复用同一管理员会话，不出现第二次组织登录或单独的运维退出。

角色由服务端正式名册和已验证会话决定。SSH 登录成功只是连接步骤；应用不会再把只有 SSH 权限的状态显示成完成的管理员登录。注销或撤销管理员身份后，工作与服务器功能一起失效。

## 服务端接入

管理员执行器复用当前经过验证的 QuantCode 原生引擎。`quantadmin` 的正式身份为 `role=admin`，授权覆盖八个业务组；执行器使用自己的工作目录、模型连接和私有会话记录。

Server C 的管理员连接文件位于 `~quantadmin/.quantcode/admin/connection.json`。桌面自动读取和建立连接，不要求用户手填 URL、端口或密码。私钥正文始终留在本机。

`scripts/setup_unified_admin.py` 负责审核当前管理员公钥、追加正式管理员记录、准备执行器与模型连接、下发连接文件及验证服务。默认仅读取计划，`--apply` 才执行。脚本保留名册备份并拒绝覆盖冲突身份，复用已有的不可变执行器资源。

从旧版仅 SSH 的缓存升级时，需要完成一次正式管理员登录。此后有效会话可直接恢复整个工作台。
