# Test V1.0 验收与使用范围

版本：`1.0.0-test.1`。分发类别：`internal-test`。发布包和校验清单以 [GitHub Release](https://github.com/HKUST-QUANT-SOCIETY/quantcode/releases/tag/quantcode-v1.0.0-test.1) 为准。

## 已验证的基础流程

八个组各使用一个独立模拟成员，在隔离研究服务器上完成真实模型任务。测试输入为明确标注的合成数据，任务、审批、文件和产物由原生执行器实际生成。

- SSH Agent 签名登录，组和权限由组织名册绑定。
- 选择授权工作区，查询能力目录和本组 Memory。
- 提交任务，暂停等待精确审批，使用“继续执行”保留原任务意图。
- 实际读写文件，发布任务记录，下载产物并核对 SHA256。
- 重新登录后恢复模型和历史，再执行真实 Memory/MCP 查询。
- 112 项跨成员任务和产物访问拒绝检查，双方使用相同 URL 和版本；同时验证 owner 正向读取、自读以及最终登出撤销。
- macOS 安装包内实际添加服务器、登录、设置模型、提交任务、审批、继续、下载核对和退出登录。

## 测试版限制

1. 这是用于成员试用的内部预发布，安装包未经过平台代码签名，自动更新关闭。
2. Agent 的研究宿主与组织网关需要常驻运行；只有安装桌面包不能替代服务器部署和成员登记。
3. 量化组件需要实际的数据、服务和授权。基础 Agent 验收不代表所有因子、训练、风险、回测或估值业务链路已接通。
4. 普通成员只能操作自己的授权工作区和已发布工具，不能通过 Agent 部署生产系统。
5. 原始 1300 条历史 nodeid 的对账为 1201 个同名保留、38 个映射、48 个被新规格替代、13 个仍缺完整等价证明；未声称原 1300 条全部通过。
6. macOS 原生文件选择对话框的人工验收仍待补充；本机锁屏期间已用 Electron 自动化验证可执行的桌面流程。

版本、文件大小、SHA256、构建提交和平台信任状态以同一 Release 中的 `release-manifest.json`、`SHA256SUMS` 为准。
