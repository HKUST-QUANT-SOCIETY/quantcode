# QuantCode Test V1.2 · Windows SSH Agent 修复

版本：`1.2.0-test.4`。本次修复在桌面安装包中，现有 Server C 服务和成员登记无需为此更新。

## 更新内容

- Windows SSH Agent 未启动时显示「启用 SSH Agent 并继续登录」。成员点击后由 Windows 请求管理员授权，启用服务并设置开机自动启动；应用确认 Agent 可访问后，复用已经选择的私钥继续探测。
- 使用「已有 SSH 身份」时，同样支持服务恢复，成功后返回身份列表，不要求重新选择私钥文件。
- 区分缺少 OpenSSH 客户端、缺少 Agent 服务、服务停止、工具权限不足、响应超时和服务已运行但无法访问。缺少组件时可从应用打开 Windows 可选功能，安装后重新检查。
- 本机 Agent 故障不再显示无关的用户名纠错表单。取消系统授权可以重试；关闭登录页面后不会在后台自动继续登录。
- 已正常运行的 Agent 不会触发系统授权。提权命令仅管理 Windows 的 `ssh-agent` 服务，不包含私钥路径、私钥内容或服务器连接参数。

## 安装与检查

[下载修订包](https://github.com/HKUST-QUANT-SOCIETY/quantcode/releases/tag/quantcode-v1.2.0-test.4)。完全退出旧版，再安装对应架构的新包；保留原有私钥和账号。

Windows 成员选择原私钥后，若看到 Agent 提示，点击「启用 SSH Agent 并继续登录」并确认 Windows 系统授权。之后填写原 SSH 用户名、选择业务组工作区。没有本机管理员授权时，需要该电脑的管理员协助启用服务。

开发回归覆盖授权取消后重试、保留密钥选择、重复点击、缺少组件、已有 Agent 身份和页面关闭。Windows 发布检查从禁用的真实 SSH Agent 服务开始，验证程序启用服务、自动启动配置、密钥导入、签名校验与退出；系统授权弹窗交互由成员在本机验收。

仍为未做平台代码签名的内部测试预发布，自动更新关闭，需要手动安装。成员公钥与服务器名册不一致的问题仍应按实际登记处理。
