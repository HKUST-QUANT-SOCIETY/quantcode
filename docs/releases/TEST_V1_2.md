# QuantCode Test V1.2

版本：`1.2.0-test.1`  
标签：`quantcode-v1.2.0-test.1`  
发布日期：2026-09-13

## 本次更新

- SSH 登录分开处理私钥选择与服务器探测，文件选择器跟随应用窗口；探测支持取消和超时恢复，连接异常后保留重试入口。
- 管理员一次认证进入完整工作台，组织名册补足授权业务组，成员继续使用独立 Linux 账号与个人目录。
- 新建任务时先确认名称和工作目录；打开已有任务后持续对话，沿用原任务及目录。
- 恢复知识库正文、能力目录、算法目录、GitHub 连接和终端入口；内容可用范围仍由宿主配置与组织授权决定。
- GitGraph 降低响应式依赖和重复排序开销，离开页面后卸载图谱；SSH 隧道增加固定端口恢复，保存的任务不再随临时端口变化失联。
- 宿主身份请求合并、名册解析复用、任务摘要并发限制和 Gateway 请求上限降低资源占用。
- HumanGate 恢复正文边距、工具栏对齐和紧凑空状态；知识库搜索栏修复按钮竖排及异常拉伸，窄窗口自动换行。

## 手动验收

1. 在知识库调整窗口宽度，确认搜索、全部知识和范围筛选可用，按钮文字保持横排。
2. 打开 HumanGate，确认内容边距、刷新按钮和审批卡片布局正常。
3. 重新登录：选择本地私钥、点选授权工作组，检查取消与重试入口。
4. 创建任务后发送两条消息，再从任务列表打开，确认对话与工作目录保持不变。
5. 检查知识正文、能力与算法目录、GitHub 及终端能否在当前授权宿主上使用。

自动化检查覆盖应用、桌面桥、原生执行器及 Python 服务；发行流水线执行三平台安装包启动检查、清单完整性与远端校验和核对。以上交互与视觉体验由使用者手动验收；安装包不会替代远端宿主的部署，也不会内置任何成员私钥或模型凭据。
